## 练习 1：print、引号、转义（`ex1.py`）

**目标**：练 `print`、单双引号、`\n` 换行、输出中文和引号。

**要求**：用 `print` 输出下面 4 行，其中**第 3、4 行必须由一次 print 用 `\n` 输出**：

```
=== 实验记录 ===
智能体A说："证据1支持结论"
智能体B说：'我不同意'
完成
```

**验收标准**：运行后屏幕上正好 4 行，顺序和标点完全一致。

**提示**：
- 想在字符串里输出双引号，外面就用单引号包：`'他说："你好"'`
- `\n` 是"换行符"，写在一个字符串中间，打印出来就是两行

**常见错误**：
- 用了中文引号 `“”` → `SyntaxError: invalid character '“'`
- 第 3、4 行写成两次 print → 不符合要求（但能跑，先记下来，回头改）

## 练习 2：变量、f-string、类型（`ex2.py`）

**目标**：练变量的定义和使用、`f-string` 字符串插值、`type()`。

**要求**：

1. 定义 3 个变量：
   - `agent_name`，值是 `"A"`
   - `claim`，值是 `"新闻为真"`
   - `confidence`，值是 `0.7`
2. 用**一行 f-string** 输出：

```
我是智能体A，我的主张是"新闻为真"，置信度0.7
```

3. 用 `type()` 打印这三个变量各自是什么类型（3 行，格式随意但要看得出是 str 还是 float）。
4. 再用 `+` 字符串拼接，输出**同样的一句话**（体会 f-string 和 `+` 的区别）。

**验收标准**：第 1 行和上面完全一致；后面能看到 `<class 'str'>` 和 `<class 'float'>`；最后一行又出现一次那句话。

**提示**：
- `=` 是赋值（把右边放进左边），不是数学里的"等于"
- `f"..."` 里的 `{变量名}` 会被自动替换成变量的值

**常见错误**：
- `print(f"我是智能体{name}")` 但变量叫 `agent_name` → `NameError`
- 用 `+` 拼接时把数字直接加进去 → `TypeError: can only concatenate str (not "int") to str`

## 练习 3：数字运算与格式化（`ex3.py`）

**目标**：练整数/小数运算、`/` 除法、f-string 保留小数位。

**要求**：

1. 定义 3 个 token 用量：`t1 = 1200`、`t2 = 980`、`t3 = 1560`
2. 定义单价：`price_per_token = 0.000002`（元）
3. 计算：总量、平均量、总费用
4. 输出（**数字必须是算出来的**）：

```
总计 3740 token，平均 1246.67 token
估算费用 0.0075 元
```

**验收标准**：两行数字完全一致。

**提示**：
- `{x:.2f}` 表示"保留 2 位小数"，`{x:.4f}` 表示 4 位
- 平均值会有除不尽的情况，所以要格式化

**常见错误**：
- 忘了 `.2f`，输出一长串 `1246.6666666666667` → 不算错，但没过验收
- 把 `3740` 手写进字符串 → 违反"必须算出来"的规则

## 练习 4：类型转换与比较（`ex4.py`）

**目标**：理解"字符串"和"数字"是两种东西，学会 `int()` 转换。

**要求**：

1. 定义两个**字符串**：`s1 = "42"`、`s2 = "8"`
2. 输出它们直接相加的结果
3. 用 `int()` 转换后相加，输出结果
4. 输出两行类型说明（照着抄格式）：

```
"42" 是字符串，转换成数字后是 42
42 > 8 的结果是 True
```

5. 最后用 `type()` 打印 `s1` 和 `int(s1)` 的类型，证明它们不一样

**验收标准**：前两行分别是 `428` 和 `50`；剩下几行和上面要求一致。

**提示**：
- 字符串 `"42" + "8"` 得到 `"428"`（拼接），不是 50
- `int("42")` 才是数字 42
- 比较运算 `>` 的结果是 `True` 或 `False`

**常见错误**：
- `"42" + 8` → `TypeError`（字符串不能直接加数字）
- 以为 `int("42")` 会改变 `s1` 本身（不会，它只是"转出来一个新值"）

## 练习 5：用 input 读输入（`ex5.py`）

**目标**：让程序接收用户输入，并处理 `input()` 返回的永远是字符串这件事。

**要求**：

1. 程序先问：`请输入智能体名字：`
2. 再问：`请输入置信度：`
3. 然后输出：

```
智能体 A 的置信度是 85.0%
```

（假设用户输入 `A` 和 `0.85`）

**验收标准**：输入 `A` 和 `0.85`，输出正好那一行；输入别的名字和小数也要正确。

**提示**：
- `name = input("请输入智能体名字：")`
- `input()` 拿回来的是**字符串**，要算数必须先 `float()`
- 百分数 = 小数 × 100，保留 1 位小数用 `{x:.1f}`

**常见错误**：
- 忘了 `float()` → 报错，或者输出变成 `0.8585.0%` 这种怪东西
- 把 `input()` 的提示文字和 `print` 混在一起，导致输入提示重复两遍

## 练习 6：综合——三个智能体表态（`ex6.py`）

**目标**：把前 5 题串起来。这是你 W1 的"毕业作品"，也是第 9 周多智能体系统的雏形。

**要求**：

1. 定义 9 个变量（命名要规范）：

| 智能体 | 名字变量 | 主张变量 | 置信度变量 |
|---|---|---|---|
| A | `a_name` | `a_claim` | `a_conf` |
| B | `b_name` | `b_claim` | `b_conf` |
| C | `c_name` | `c_claim` | `c_conf` |

2. 赋值：

| | 名字 | 主张 | 置信度 |
|---|---|---|---|
| A | `A` | `新闻为真` | `0.70` |
| B | `B` | `证据不足` | `0.55` |
| C | `C` | `新闻为真` | `0.90` |

3. 输出一张表（列之间用 `\t` 分隔即可，不要求像素级对齐）：

```
智能体	主张	置信度
A	新闻为真	0.70
B	证据不足	0.55
C	新闻为真	0.90
平均置信度：0.72
```

4. 最后一行的 `0.72` **必须由程序算出来**（三数相加除以 3，保留 2 位小数）。

**验收标准**：4 行数据 + 1 行平均，数字正确，置信度都是两位小数。

**提示**：
- 一行里想输出多个东西，可以用 `\t` 隔开，或者 `print(a, b, c)`（默认用空格隔开）
- 平均值：`(a_conf + b_conf + c_conf) / 3`

**常见错误**：
- 直接 `print("平均置信度：0.72")` → 违反规则
- 三个数都是 `str` 类型（加了引号），相加变成字符串拼接 → 算出来是 `"0.700.550.90"`
